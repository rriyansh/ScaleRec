# ScaleRec

End-to-end recommendation stack: Two-Tower retrieval + FAISS index + XGBoost ranker + FastAPI inference API.

## Structure

```
scalerec/
├── data/               # Synthetic users, items, interactions (generated by src/data_prep.py)
├── models/             # two_tower.pt, faiss_index.bin, xgb_ranker.json
├── src/
│   ├── data_prep.py    # Synthetic data generation
│   ├── two_tower.py    # Two-Tower model (PyTorch)
│   ├── train_two_tower.py
│   ├── build_faiss.py
│   ├── train_ranker.py # XGBoost ranking model
│   └── serve.py        # FastAPI inference API
├── requirements.txt
└── README.md
```

## Setup

```bash
cd scalerec
pip install -r requirements.txt
```

## Run

1. Generate synthetic data:
   ```bash
   python src/data_prep.py
   ```

2. Train the Two-Tower model:
   ```bash
   python src/train_two_tower.py
   ```

3. Build the FAISS index:
   ```bash
   python src/build_faiss.py
   ```

4. Train the XGBoost ranker:
   ```bash
   python src/train_ranker.py
   ```

5. Serve inference API:
   ```bash
   python src/serve.py
   ```

Then POST to `http://localhost:8000/recommend` with `{"user_id": 42, "top_k": 10}`.
